# Cluster source audit and correctness checkpoint

Date: 2026-10-12 (Asia/Seoul). Baseline commit: `a998077419fd59d91141ce2b9b1fe48ae0d2d7aa`. The working tree was clean before the audit. This checkpoint contains fixes and regressions, not a production certification. No dependencies were added.

## Reproducible verification

Baseline commands all succeeded: `cargo fmt --check`, `cargo clippy --all-targets --all-features -- -D warnings`, `cargo test --all-targets` (262 library tests), `cargo build --release`. Their unedited output is in [baseline-fmt.log](baseline-fmt.log), [baseline-clippy.log](baseline-clippy.log), [baseline-test.log](baseline-test.log), and [baseline-release.log](baseline-release.log). Passing existing tests did not establish the invariants below.

Final commands, exit codes, elapsed time and log paths are recorded in [verification.json](verification.json). Final `cargo test --all-targets` reports **295 passed; 0 failed** in the library, plus successful binary, example and Criterion target executions. The 33 new `audit_` tests include numerical, data, hardware and PCB cases. Existing PCB connectivity fixtures that used unknown footprints/body origins were updated to known resistor footprints and their real pad positions; their former origin-fallback expectation was itself the defective behavior. The full output is [final-test.log](final-test.log). `cargo check`, formatting, all-target/all-feature Clippy and release also succeeded. No desktop GUI, firmware compiler, physical hardware, external Gerber viewer or fabrication service was exercised.

## Confirmed data/editor defects corrected

All entries describe pre-correction behavior. New guard defects discovered while implementing this audit are identified separately.

| Severity | Exact file / function | Root cause and reproduction | Correction / regression |
|---|---|---|---|
| P0 | `app/actions.rs::save_project_folder_to`, `load_project_folder_from` | Independent schematic and board writes could be loaded from different generations. | P0 | `app/actions.rs::SavedCircuit::from_app`, `into_snapshot` | Recovery serialized schematic only; PCB edits disappeared. Discovered during this audit implementation. |

A final extension of the ECO test adds a zone to the renumbered net. It reproduced a zone assignment remaining changed after `EcoPatch::rollback`; [failing-eco-zone-undo.log](failing-eco-zone-undo.log) records the failure. `EcoPatch::{rollback,reapply}` now captures/restores zone metadata alongside tracks, vias and bindings. This P0 undo defect was introduced by the new remapping path and corrected before the checkpoint.

The single-file commit improves process-level consistency, but does not establish power-loss durability of directory rename on every filesystem. Corrupt legacy multi-file saves cannot be reconstructed automatically. The remaining-risks report distinguishes these risks from reproduced bugs.
